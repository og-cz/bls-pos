# Progress

Short demo notes at the end of each phase.

## Phase 0 — Foundation (2026-10-29)

**Demo:** `pnpm install && pnpm dev` → open the printed URL. The page shows
"Hello, POS Fast" and **API: online**, fetched from `GET /api/v1/health` on the same
Worker. Deep links like `/some/route` fall back to the SPA. Unknown `/api/v1/*` paths
return a JSON `NOT_FOUND` error.

**Checks passing locally:** `pnpm lint`, `pnpm format:check`, `pnpm typecheck`,
`pnpm test` (2 API tests in workerd), `pnpm build` (sell-screen JS 81 KB gzipped,
budget 200 KB).

**Not yet done (needs the owner):**

- Push to GitHub so CI runs (`.github/workflows/ci.yml`).
- Preview deploy: `pnpm exec wrangler login`, then `pnpm deploy`. Needs a Cloudflare account.

**Deviations from the plan:**

- TypeScript 6.0 instead of 7.0 (typescript-eslint doesn't support 7 yet).
- `@cloudflare/vitest-plugin` instead of `@cloudflare/vitest-pool-workers` (renamed upstream).
- `worker-configuration.d.ts` is generated by `wrangler types` and committed. CI fails
  if it's stale.
